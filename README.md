# my-tool

毎日の作業をシンプルにするための小さなツールです。
現在はプロジェクトを紹介するランディングページを公開しています。

## ファイル構成

```
.
├── index.html   # ランディングページ（HTML + インライン CSS の1ファイル構成）
└── README.md
```

## ランディングページ

- ヘッダー（ロゴ・ページ内リンク）
- ヒーローセクション（キャッチコピー・ボタン）
- 特徴セクション（3つのカード）
- GitHub リポジトリへの案内
- フッター

スマホ幅とダークモード（OS の設定に連動）に対応しています。

## 使い方

ビルドやインストールは不要です。`index.html` をブラウザで開くと表示できます。

```bash
git clone https://github.com/iototoooo/my-tool.git
cd my-tool
# index.html をブラウザで開く
```
